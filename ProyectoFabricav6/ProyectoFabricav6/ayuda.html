Manual de Usuario

Navegación en los menús

Usa las teclas de flecha ARRIBA (↑) y ABAJO (↓) para moverte entre las opciones del menú.

Seleccionar una opción

Presiona la tecla ENTER (↵) para seleccionar una opción.

Salir de un menú

Presiona la tecla ESC para salir del menú actual.

Acceder a la ayuda

Presiona la tecla F2 para ver esta pantalla de ayuda.

Funcionalidades del sistema

Gestionar Clientes

Insertar Cliente: Agrega un nuevo cliente al sistema.

Buscar Cliente: Busca un cliente por RUC o nombre.

Mostrar Clientes: Muestra una lista de todos los clientes registrados.

Modificar Cliente: Actualiza la información de un cliente existente.

Eliminar Cliente: Elimina un cliente del sistema.

Mostrar Mapa General: Genera un gráfico del grafo de clientes.

Mostrar Ruta Óptima: Calcula y muestra la ruta más corta desde la fábrica hasta un cliente.

Gestionar Pedidos

Insertar Pedido: Registra un nuevo pedido en el sistema.

Confirmar Estado: Cambia el estado de un pedido (en proceso, entregado, cancelado).

Buscar Pedido: Busca un pedido por número o destinatario.

Mostrar Pedidos: Muestra una lista de todos los pedidos registrados.

Eliminar Pedido: Elimina un pedido del sistema.

Crear Backup: Guarda una copia de seguridad de los pedidos.

Restaurar Backup: Recupera los pedidos desde una copia de seguridad.

Gestionar Herramientas

Insertar Herramienta: Agrega una nueva herramienta al inventario.

Cambiar Stock: Modifica la cantidad de una herramienta en el inventario.

Buscar Herramienta: Busca una herramienta por ID o nombre.

Mostrar Herramientas: Muestra una lista de todas las herramientas registradas.

Modificar Herramienta: Actualiza la información de una herramienta existente.

Eliminar Herramienta: Elimina una herramienta del inventario.
